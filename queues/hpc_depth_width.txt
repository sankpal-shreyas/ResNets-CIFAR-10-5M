# Depth vs width study on HPC Cloud Bursting (1 x A100 per job):
#   RETRIES=1 bash scripts/hpc/submit_jobs.sh cs_gy_6923-2026fa c12m85-a100-1 queues/hpc_depth_width.txt
# (each run = 1 job + 1 standby job that starts only if the first ends unsuccessfully)
#
# Pre-activation Wide ResNet, depth = 6n + 4 (n blocks per stage), widths = 3 stage widths.
# Every run uses the same recipe so only the architecture changes: configs/wrn28_ta.yaml as is
# (TrivialAugment + Cutout 16, label smoothing 0.1, EMA, SGD-Nesterov lr 0.1, cosine, 200 epochs,
# seed 0, 45k/5k split) -- the protocol of the earlier 200-epoch screens (a0-a6, b1-b4), so all of
# them compare directly. dwA_d28_w64 repeats a0 (97.12 / 97.54, no TTA / flip_shift): a check that
# this setup reproduces it. Analysis: notebooks/depth_width.ipynb.

# --- A. equal budget (4.73-4.99M params, 713-799M MACs): trade depth for width ----------------

configs/wrn28_ta.yaml --set name=dwA_d34_w56 model.depth=34 model.widths=[56,112,200]
configs/wrn28_ta.yaml --set name=dwA_d40_w48 model.depth=40 model.widths=[48,96,184]
