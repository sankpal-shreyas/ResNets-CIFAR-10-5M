# Augmentation multiplicity on top of k25f (HPC, 1 x A100 each, ~13 h):
#   RETRIES=1 bash scripts/hpc/submit_jobs.sh cs_gy_6923-2026fa c12m85-a100-1 queues/hpc_aug_multiplicity.txt
#
# Exactly k25f's run (same 6 teachers, T=4, alpha 0.1, TrivialAugment + Cutout + CutMix/MixUp on every
# batch, 3200 epochs, all 50k images) with one change: data.repeats. Each batch of 128 holds 128/r
# different images, each in r independently augmented (and independently mixed) copies, and the
# teachers label every copy (Fort et al. 2021, "Drawing multiple augmentation samples per image during
# training efficiently decreases test error"). Epoch length and cost per epoch are unchanged.
#
# Needs the teacher checkpoints in runs/<name>/model_final.pt (upload p1_teachers.zip, see
# scripts/hpc/README.md). Decision rule, fixed before the runs: replace k25f only if a run beats it on
# the CIFAR-10 test batch (flip_shift) by >= 0.3 points with paired McNemar p < 0.1; otherwise k25f
# stays and this is reported as a tested idea.
